A portfolio has two audiences. A visitor wants a quick answer. The person who made it wants to include every detail that proves the work mattered.

Those goals fight each other.

## Start with the question

The useful question was not, "What projects should I show?" It was, "What should someone understand about me after thirty seconds?"

That changed the page from an archive into a sequence.

![Earth at night, used as temporary visual material](/textures/earth-blue-marble.jpg)

## Interaction as editing

Animation can reduce noise when it controls when information appears. It can also create noise when every object asks for attention.

The rule became simple: motion must explain hierarchy, feedback, or a state transition. Everything else stays still.

## The unfinished part

The portfolio will never be complete because the person it represents keeps changing. That is not a flaw. It is the reason to build a system that can keep being edited.
